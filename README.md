### What I work on

- 🤖 **Agentic systems:** multi-agent setups and durable agents with tools, schedules and webhooks, built on Claude Code and the Claude API
- ⚙️ **AI automation for small businesses:** turning repetitive founder work into reliable workflows. One finance agent uncovered €4,438 in hidden outflows and 9 forgotten subscriptions for a client
- 🛒 **Full-stack products:** web shops, CRMs and client portals with Next.js, Supabase, Stripe and Vercel
- 📱 **Native Apple apps:** local-first tools written in Swift

### Featured project

**[facs-character-continuity](https://github.com/Cittasana/facs-character-continuity)**
An Agent Skill for Claude that keeps AI-generated characters consistent across images, angles, expressions and short video scenes, using FACS-informed character sheets, expression cards and generator-ready prompts.
